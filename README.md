# Algorand Student Certificate Verification

## Project Overview

This project aims to develop a blockchain-based student certificate verification system using the Algorand blockchain.

The system will help verify the authenticity of student certificates using blockchain technology.

## Objectives

- Store certificate verification information securely.
- Use the Algorand blockchain for verification.
- Reduce the possibility of certificate forgery.
- Provide a simple method to verify certificate information.

## Technology

- Algorand Blockchain
- Smart Contracts
- GitHub

## Project Status

Project development will be carried out as part of the Algorand Blockchain Developer course.

## Future Scope

The project will be further developed during the course with additional blockchain functionality, testing, and deployment.
